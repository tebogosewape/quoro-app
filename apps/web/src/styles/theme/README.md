# Theme Folder

This directory houses the enterprise theme primitives for the web client.

- `tokens.css` – Canonical design tokens (colors, spacing, motion, feedback). Update these values to tweak the global look and feel.
- `components.css` – Bootstrap-aware component overrides that read from the tokens.
- `index.css` – Single import point used by `apps/web/src/main.tsx`.

> Looking for usage guidance? See `documentation/ENTERPRISE_THEME.md`.
